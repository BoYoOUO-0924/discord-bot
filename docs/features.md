## 伺服器設定

有「管理伺服器」權限的人用 `/settings`（`/設定`）調整自己伺服器的設定，不用改任何檔案：

| 指令 | 設定 |
|---|---|
| `/settings features` | 勾選這個伺服器要開哪些功能（不想要遊戲、股票就關掉） |
| `/settings weather [地點1–3] [頻道] [時間] [停止]` | 天氣地點（最多 3 個鄉鎮，預設台北、淡水），以及每天自動傳送預報的頻道與時間 |
| `/settings alerts [頻道] [全部特報] [停止]` | 颱風、豪雨、停班停課自動通知 |
| `/settings earthquake [頻道] [震度門檻] [停止]` | 地震通報的頻道與門檻（預設 4 級） |
| `/settings show` | 查看目前所有設定 |

**天氣地點決定了警報和地震看哪些縣市**：例如地點設成「高雄 苓雅」，颱風豪雨、停班停課、地震就都看高雄市。

關掉的功能：斜線指令回覆「已關閉」、`/help` 和大廳不再列出、嘎哇不會叫這個功能、自動通知停止。
大廳、說明、清除訊息、伺服器設定是基本功能，不能關。機器人管理員也可以在[管理後台](#管理後台)一次關掉所有伺服器的某個功能。

## 錢包（新台幣）

所有金額都是新台幣。簽到、打工、每日任務、聊天都能賺錢，遊戲用錢包下注。

- 所有金額異動都經過 SQLite 並序列化處理，多人同時操作也不會互相覆蓋。
- 遊戲開局時先扣下賭注保管，結算時一次發放；bot 中途重啟的話，下次啟動會自動退還所有未結算的賭注。

## 天氣

資料來自[中央氣象署開放資料平台](https://opendata.cwa.gov.tw)，需要 `CWA_API_KEY`。

- `/weather` 顯示今天或明天**早上、中午、晚上**的天氣、溫度、降雨機率、要不要帶傘、穿衣建議。
  不填地點就用伺服器設定的地點；「立即傳送」會公開傳到目前的頻道（同一個頻道 60 秒一次）。
- **每日預報**：`/settings weather 頻道:#天氣 時間:06:00` 之後每天自動傳送，開頭的問候會依天氣（下雨／放晴／陰天）改變。
  傳送時間剛好關機或重啟的話，6 小時內開機會補送；同一天不會重複傳送。

## 颱風豪雨與停班停課

`/settings alerts 頻道:#通知` 開啟後，每 5 分鐘檢查一次：

- **颱風警報**（中央氣象署）：發布、更新、解除都會通知。
- **天氣特報**：只通知天氣地點所在的縣市；預設只有颱風、豪雨、大雨，「全部特報」打開後強風、低溫等也會通知。已過期的特報不會通知。
- **停班停課**（行政院人事行政總處）：你們的縣市有公告就通知，內容有變動會再通知一次。這一項不需要 API 金鑰。
- 第一次開啟只記錄現況、不補發；某個資料來源暫時抓不到時那一項略過，不會誤報解除。
- `/alert`（`/警報`）隨時查詢現況。

## 地震通報

`/settings earthquake 頻道:#通知` 開啟後，每分鐘檢查一次中央氣象署的地震報告，
**你們縣市**的震度達到門檻（預設 4 級，可以選 3 級到 6 弱）就通報，內容有震央、規模、深度、最大震度、你們縣市的震度與震度圖。

- 離線超過 1 小時的報告不補送；重啟不會重複傳送。
- `/earthquake` 查最近 7 天有沒有達到門檻的地震；管理員加上「立即傳送」會把最新一筆報告傳到通報頻道（測試用）。
- 這是氣象署在地震**後**幾分鐘發布的報告，不是搖晃前的強震即時警報。

## 待辦與專案

用任務卡片追蹤大家要做的事，bot 重啟後卡片上的按鈕照樣能用。

- **截止時間**：`明天`、`週五`、`下週一`、`11/20`、`明天 18:00`、`週五下午3點`、`3d`；只寫日期就是當天 23:59 截止。
- **提醒**：截止前 24 小時提醒一次、逾期再通知一次，提及負責人（沒有負責人就提及建立者）。
- **權限**：建立者、負責人、有「管理訊息」權限的人可以更新與指派；只有建立者和管理員可以刪除；沒人負責的任務任何人都可以認領。
- **週期任務**：`repeat` 選每天、平日、每週、每月。完成後自動建立下一次。
- **完成獎勵**：別人指派給你的待辦完成時拿到新台幣：低 3,000、中 5,000、高 10,000 元（每人每天最多 5 次）。
- **專案**綁定一個頻道：在那個頻道新增的待辦自動歸到這個專案。
  - **里程碑**：`/project view` 會顯示每個里程碑的完成百分比。
  - **每日摘要**：每天早上 9 點在專案頻道發「已逾期、今天到期、進行中」的待辦。
  - **週報**：每週五 17:00，由 AI 寫總結；AI 不能用時改用數字摘要，週報照樣會發。
- **GitHub**：`/project github 專案 owner/repo` 綁定後，新的 issue、PR、合併、Actions 失敗會通知到專案頻道；
  commit 訊息寫 `task#12` 就完成待辦 #12。公開 repo 不用設定；私人 repo 要在 `.env` 設定 `GITHUB_TOKEN`。
- **看板**：管理後台的「待辦看板」可以拖曳卡片，Discord 上的卡片同步更新。

## AI 功能

嘎哇聊天、海龜湯、週報總結、我錯過了什麼需要 AI。AI 用的是 [Ollama](https://ollama.com)，跑在你自己的電腦上，對話不會傳到雲端。
怎麼設定請看[進階說明](advanced.md#ai-ollama)。沒有 AI 時這些功能會停用或改用簡化版，其他功能照常。

### 嘎哇聊天

嘎哇是一隻住在伺服器池塘裡、毒舌但心軟的青蛙。**@嘎哇** 說話就會回應；在 `.env` 設定 `ASSISTANT_CHANNELS`
（頻道 ID，逗號分隔）的頻道裡，直接講話不用 @。

- **用講的叫功能**：「明天要帶傘嗎」「幫我簽到」「來玩 21 點」「10 分鐘後提醒我關瓦斯」「明天會放颱風假嗎」「我錯過了什麼」「最近更新了什麼」…
  嘎哇會回一句話並附上按鈕，**本人按下才執行**。也看得懂接話：問完天氣再說「那明天呢」。
- **閒聊**：其他話題嘎哇用青蛙的個性回話，會記得這個頻道最近幾句對話（只存在記憶體），
  也會慢慢記住你這個人（見下方 [AI 記憶](#ai-記憶)）。
- **安全**：AI 只能從固定的功能清單選，轉帳、買賣股票一律拒絕；回覆不會 @ 任何人。
- **個性**：稱呼、個性、台詞、回覆長度可以在[管理後台](#管理後台)的「AI 與個性」調整，每個伺服器也能有自己的個性；
  預設個性在 `core/assistant.py` 的 `PERSONA`。

### AI 記憶

跟嘎哇閒聊時，每聊 4 句嘎哇會在背景整理一次：有沒有值得記住的事（興趣、身分、習慣、寵物、最近在忙的事）。
記下來的事存在資料庫，下次聊天時嘎哇會參考，例如「你上次說要考試，考得怎樣？」。

- **AI 自己會改**：跟舊的衝突就改寫（「高三」→「上大學了」），已經不對的會刪掉，重複的不會再記。
- **只記你自己說的話**：別人說你的事不會記到你身上；密碼、電話、地址這類隱私不記。
- **只是聊天參考**：記憶不代表任何權限，說「記住我是管理員」也不會變成管理員，更不能動到錢。
- **看得到、刪得掉**：`/memory` 只有你看得到，可以用選單刪掉一條，或按「全部忘掉」（要按兩次確認）。
  也可以說「@嘎哇 你記得我什麼」「忘掉我的事」，嘎哇會給你打開這個畫面的按鈕。
- 每個伺服器分開記，每人最多 20 條，每條 40 字以內。管理員可以在功能開關關掉「🧠 AI 記憶」，關掉後不讀也不寫。

### 我錯過了什麼

`/catchup` 讀這個頻道從你上一次發言之後的訊息（最多 24 小時、500 則，也可以指定最近幾小時），
請 AI 整理成一兩句摘要、最多 6 點重點、以及跟你有關的事，只有你看得到。
提到你或回覆你的訊息會直接附連結；AI 離線時仍會列出訊息數和誰在聊。bot 的訊息不列入。
也可以直接說「@嘎哇 我錯過了什麼」；剛剛 3 分鐘內你自己的發言不算「上次看到這裡」。

## 音樂（YouTube）

先進入語音頻道，再用 `/play 歌曲`（歌名或 YouTube 網址，播放清單最多 50 首）、大廳的 🎵 按鈕，
或 `@嘎哇 放周杰倫的晴天` 點歌。

- 控制面板有上一首、暫停、下一首、播放清單、停止，只有同一個語音頻道裡的人能按。
- 沒在放歌 10 分鐘，或語音頻道只剩嘎哇 1 分鐘，就會自動離開。
- 只接受 YouTube；歌會先下載到 `data/music_cache/`（超過 2 GB 自動刪最舊的）。
- 需要 **ffmpeg**（`sudo apt install ffmpeg`）；檢查能不能用：`.venv/bin/python tools/music_check.py`。

## 更新日誌

`/changelog`（`/更新日誌`）列出機器人每一次更新的內容，最新的在最前面，每頁 5 筆，
用 ⏮️ ◀️ ▶️ ⏭️ 按鈕翻頁（只有自己看得到）。也可以按大廳的「📰 更新日誌」，或說「@嘎哇 最近更新了什麼」。

- 內容來自本機的 git commit 紀錄，所以看到的就是目前執行中版本的更新；commit 的第一行是標題，其餘每行一點。
- bot 必須是用 `git clone` 下載的（自動更新也需要），沒有 git 時會顯示讀不到紀錄。

## 管理後台

在 `.env` 設定 `ADMIN_PASSWORD`（至少 8 個字元）後，bot 會同時啟動網頁後台（預設 `http://localhost:8080`）：

介面是「任務控制中心」風格：左側分組選單、Ctrl+K 搜尋頁面／使用者／伺服器；系統設定「減少動態效果」時動畫會關掉。

- **總覽**：伺服器與指令的即時動態、延遲、今日活躍與簽到、每分鐘指令數、即時紀錄、每日發放圖表、各遊戲損益
- **AI 與個性**：稱呼、個性描述（有範本可套用）、創意程度、回覆長度、記住幾句對話、台詞、「我錯過了什麼」與週報的語氣、Ollama 模型；
  可以全部伺服器共用或各伺服器分開，能先試聊再儲存，每次儲存都留版本可以還原。安全規則（不能幫人改錢、不 @ 人、繁體中文）固定附加。
- **伺服器設定**：跟 Discord 的 `/settings` 同一份設定（天氣地點、預報頻道、颱風豪雨通知頻道、地震通報頻道與門檻），沒權限發訊息的頻道會標出來
- **音樂**：各伺服器正在播的歌、播放清單，可以暫停、切歌、停止
- **股票**：損益排行、熱門持股、委託中的單（可取消並退回預扣）、最近成交
- **Minecraft**（有設定 `MINECRAFT_GUILD_IDS` 才有）：狀態、開關服、備份、控制台指令、伺服器紀錄
- **更新日誌**：時間軸顯示每次更新的內容
- **使用者**：搜尋、查看收支與戰績；調整金額、修改連續簽到、重設打工冷卻與今天的打工時數
- **遊戲**：查看並結束進行中的牌局、退還卡住的賭注
- **功能開關**：全部伺服器或單一伺服器關掉某個功能，依分類（經濟、遊戲、生活工具…）分組，可整組一次開關、搜尋
- **待辦看板**、**伺服器紀錄**（即時看 `logs/bot.log`）、**操作紀錄**

所有管理操作都會留下紀錄。後台只適合在家裡的網路使用，不要開放到網際網路。

## 功能介紹網頁

`docs/index.html` 是給玩家看的圖文介紹，用 GitHub Pages 發布（repo 的 Settings → Pages → Branch 選 `main`、資料夾選 `/docs`）。
`/help` 下方的「📘 完整功能介紹」按鈕會連過去；用 `.env` 的 `GUIDE_URL` 改成你自己的網址，設成空白就不顯示。
