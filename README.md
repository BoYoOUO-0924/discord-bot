# 嘎哇 Discord Bot

一個以**斜線指令**操作的 Discord 遊戲與工具機器人：新台幣錢包（簽到、打工、財富排行榜）、股票模擬、21 點、拉霸機、猜數字、井字遊戲、德州撲克，以及由 AI 擔任湯主的海龜湯。

輸入 `/menu` 打開大廳，所有功能都能用按鈕操作；介面語言是中文的使用者會看到中文指令名稱（例如 `/簽到`）。

## 安裝與啟動

1. **建立虛擬環境並安裝套件**（需要 Python 3.10 以上）
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # macOS / Linux：source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. **設定金鑰**：所有 Token、API 金鑰、網址都放在 `.env`。把 `.env.example` 複製成 `.env`（和 `bot.py` 同一層），填入：
   ```
   DISCORD_TOKEN=你的 Discord Bot Token
   # 選填：海龜湯的 AI 湯主（Ollama，沒設定只會停用海龜湯）
   OLLAMA_URL=http://100.123.111.120:11434
   OLLAMA_MODEL=gemma4:e4b-it-q4_K_M
   ```
   格式是 `名稱=值`，不用加引號。`.env` 已被 `.gitignore` 排除，不會上傳。也可以改用同名的環境變數（環境變數優先）。
   > 以前用 `config.py` 的話還是能讀到，但啟動時會提醒把設定搬到 `.env`，搬完就可以刪掉 `config.py`。

3. **Discord Developer Portal 設定**
   - Bot 頁面開啟 **Message Content Intent**（猜數字與海龜湯要讀取頻道訊息）
   - 邀請時勾選 scope `bot` 與 `applications.commands`，權限至少需要
     Send Messages、Embed Links、Add Reactions、Read Message History（`/clear` 另需 Manage Messages）

4. **啟動**
   ```bash
   python bot.py
   ```
   第一次啟動會自動把舊版 `data/points.json`、`data/checkin.json` 匯入資料庫（原檔不會被修改）。
   開發時可以在 `.env` 設定 `DEV_GUILD_ID`，斜線指令只同步到該伺服器並立即生效。

## 錢包（新台幣）

所有金額都是新台幣（舊版的積分在第一次啟動新版時自動換算：1 分 = 100 元，只換算一次）。
簽到、任務、聊天獎勵、猜數字與海龜湯獎勵都是舊版的 100 倍；打工改成依工作內容領真實行情的薪水。

## 股票模擬

用錢包裡的新台幣買賣台股（上市股票與 ETF），賣出的錢回到同一個錢包。

- **行情**：報價先查證交所即時行情（約 5 秒更新），查不到時用 [twfolio](https://github.com/BoYoOUO-0924/tw-stock-portfolio) 的每日收盤資料；
  股票清單、走勢、本益比、交易日曆都來自 twfolio 的資料庫（唯讀開啟，不會修改）。
- **成交規則**：交易日 9:00–13:30 立刻用即時價成交（買進用最佳賣價、賣出用最佳買價，漲停買不到、跌停賣不掉）；
  其他時間變成委託單，用下一個交易日的**開盤價**成交，避免用舊價格買已經知道會漲的股票。
  委託買進先預扣「參考價 × 1.1」（台股單日漲幅上限 10%），成交後多的退回；成交或取消會私訊通知。
- **手續費與交易稅**：讀 twfolio `config.yaml` 的 `fees`（手續費 0.1425% 捨去、整股最低 20 元、零股最低 1 元；賣出交易稅股票 0.3%、ETF 0.1%）。
- **設定**：預設讀 `C:\twfolio\data\twfolio.db` 與 `C:\twfolio\config.yaml`，裝在別的地方就在 `.env` 設定 `TWFOLIO_DB`、`TWFOLIO_CONFIG`。
  找不到資料庫時 `/stock` 會停用，其他功能照常。twfolio 由工作排程每個平日 18:30 更新行情。

## 每日天氣預報

每天早上 6 點（台灣時間）用 Discord Webhook 一次傳送**台北**與**淡水**今天**早上、中午、晚上**的天氣：
天氣狀況、溫度、降雨機率、會不會下雨（要不要帶傘）。開頭的問候會依天氣（下雨／放晴／陰天）改變。
穿衣建議只在 `/weather` 指令裡顯示。資料來自[中央氣象署開放資料平台](https://opendata.cwa.gov.tw)。

1. 到中央氣象署開放資料平台註冊並登入，在「取得授權碼」複製 API 授權碼。
2. 在 Discord 要接收預報的頻道：**編輯頻道 → 整合 → Webhook → 新 Webhook**，複製 Webhook 網址。
3. 在 `.env` 加上：
   ```
   CWA_API_KEY=你的授權碼
   WEATHER_WEBHOOK_URL=https://discord.com/api/webhooks/...
   # 選填，預設 06:00
   WEATHER_TIME=06:00
   ```
4. 重新啟動 bot。紀錄裡出現「每日天氣預報已啟用」就成功了，可以用 `/weather` 立即預覽。

- 傳送時間剛好關機或重啟時，開機後中午前會補送；同一天不會重複傳送。
- 台北使用臺北市中正區、淡水使用新北市淡水區的逐 3 小時預報；萬一抓不到會改用全市預報（只分白天／晚上），並在訊息底部註明。

## 地震報告通知

設定好 `CWA_API_KEY` 後，bot 每分鐘檢查一次中央氣象署的地震報告，**台北震度 4 級以上**時用 Webhook 主動通報，
開頭是「即使大地偶有震顫，也希望你所在的地方始終安穩。」，內容有震央、規模、深度、最大震度、台北／新北的震度與氣象署的震度圖。

- 預設傳到天氣預報的 Webhook；想傳到別的頻道就在 `.env` 加上 `EARTHQUAKE_WEBHOOK_URL=...`。
- 已傳送的報告記在 `data/earthquake_seen.txt`，重啟不會重複傳送；第一次啟動不會補送舊報告，離線超過 1 小時的也不補送。
- `/地震`（`/earthquake`）查詢最近 7 天台北有沒有震度 4 級以上的地震，沒有就會說沒有，並附上最新一筆報告；
  管理員加上「立即傳送」會把最新一筆報告（不論震度）傳到頻道，用來測試 Webhook。
- 這是氣象署在地震**後**幾分鐘發布的報告，不是搖晃前的強震即時警報。

## 管理後台

在 `.env` 設定 `ADMIN_PASSWORD`（至少 8 個字元）後，bot 會同時啟動一個網頁後台（預設連接埠 8080），
同一個網路裡的裝置可以用瀏覽器登入：

- **總覽**：使用者數、流通積分、每日發放積分圖表、各遊戲損益
- **使用者**：搜尋、查看收支紀錄與戰績；調整積分、修改連續簽到、重設打工冷卻
- **遊戲**：查看並結束進行中的牌局、退還卡住的賭注
- **伺服器紀錄**：即時查看 `logs/bot.log`，可以只看錯誤、搜尋、複製或下載完整紀錄檔；
  顯示最近 24 小時的錯誤數量，Traceback 會跟錯誤訊息完整顯示在一起
- **操作紀錄**：所有管理操作

所有管理操作都會留下紀錄。後台只適合在家裡的網路使用，不要開放到網際網路。

## 專案結構

```
bot.py              主程式：載入功能、同步斜線指令、統一錯誤處理
core/
  config.py         讀取 .env / 環境變數（相容舊版 config.py）
  weather.py        中央氣象署預報解析、穿衣與降雨建議
  db.py             SQLite 資料層（積分、簽到、下注保管、提醒、投票）
  ui.py             共用的顏色、訊息格式、按鈕介面基底
  ai.py             AI 湯主（Ollama）連線
  catalog.py        遊戲與指令目錄（大廳、說明、戰績共用）
  i18n.py           指令名稱中文化
  timeutil.py       台灣時區與時間字串解析
cogs/
  hub.py            /menu、/help
  economy.py        簽到、個人資料、排行榜、轉帳
  reminders.py      提醒
  polls.py          投票
  admin.py          /clear
  weather.py        每日天氣預報 Webhook、/weather
  blackjack.py  slots.py  guess_number.py  tictactoe.py  seatortoise.py
  poker/            德州撲克（engine.py 是不依賴 Discord 的牌局引擎）
tests/              單元測試：python -m unittest discover -s tests -t .
data/               資料庫 bot.db（不會上傳）
```

## 積分安全機制

- 所有積分異動都經過 SQLite 並序列化處理，多人同時操作也不會互相覆蓋。
- 遊戲開局時先扣下賭注保管，結算時一次發放；bot 中途重啟的話，下次啟動會自動退還所有未結算的賭注。
